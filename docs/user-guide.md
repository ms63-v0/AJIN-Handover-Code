## 2. 용어 풀이

| 용어 | 쉬운 설명 |
|---|---|
| **DB(데이터베이스)** | 데이터를 표 형태로 저장해 두는 창고입니다. 이 시스템은 `HW_Q_DB`를 씁니다. |
| **MSSQL** | DB를 관리하는 프로그램(Microsoft SQL Server)입니다. |
| **SQL** | DB에 "값을 찾아 줘", "값을 바꿔 줘"라고 말하는 명령어입니다. |
| **테이블** | DB 안의 표 하나입니다. `m_`로 시작하면 기준정보, `t_`로 시작하면 실적·이력입니다. |
| **백엔드** | 화면 뒤에서 DB 값을 읽고 쓰는 프로그램입니다. |
| **프론트엔드(화면)** | 브라우저에 보이는 부분입니다. 버튼을 누르면 백엔드에 요청을 보냅니다. |
| **API** | 화면과 백엔드가 주고받는 요청과 응답의 약속입니다. |
| **`.env` 파일** | DB 주소, 계정, 비밀번호처럼 바뀌거나 비밀인 값을 적는 설정 파일입니다. |
| **가상환경(.venv)** | 이 프로그램만 쓰는 Python 공간입니다. |
| **ODBC 드라이버** | Python이 MSSQL과 대화할 때 쓰는 연결 부품입니다. |
| **`127.0.0.1`** | "이 PC 자신"을 뜻하는 주소입니다. 다른 PC에서는 접속할 수 없습니다. |
| **CORS(허용 주소 목록)** | 백엔드가 요청을 받아 주는 화면 주소 목록입니다. |
| **커밋 / 브랜치** | 커밋은 코드 변경 1건의 기록, 브랜치는 변경 기록의 갈래입니다. |
| **LOT** | 제품 1개 단위의 생산 실적입니다(`t_lot`). 모든 실적이 LOT 번호로 묶입니다. |
| **용접부위(파트)** | 한 제품에서 용접하는 위치입니다. 화면의 "1번 파트"는 `m_weld_point.sequence_no`입니다. |
| **알람** | 설비 이상, 기준 이탈, 비전 NG 같은 **이벤트 기록**입니다(`t_alarm_event`). |
| **UCL / LCL** | 레시피의 상한·하한 기준값입니다. 벗어나면 기준 이탈입니다. |
| **PLC** | 설비를 제어하고 센서 값을 모으는 장치입니다. |
| **Kepware** | PLC 값을 읽어 DB에 기록하는 중계 프로그램입니다. |
| **태그** | Kepware에서 PLC 값 하나를 가리키는 이름입니다. |
| **해시** | 비밀번호를 알아볼 수 없게 바꾼 문자열입니다. DB에는 해시만 저장합니다. |
| **KST** | 한국 표준시입니다. 모든 시각은 KST 기준입니다. |

## 10. 화면 안내

| 메뉴 | 하는 일 | 조회 한도 | 갱신 | 읽는 테이블 | 쓰는 테이블 |
|---|---|---|---|---|---|
| 대시보드 | 생산량, 합격률, 사이클 타임, 추이, 불량 분포, 최근 알람 | 당일 | 10초 | `t_lot`, `t_loading_event`, `t_weld_event`, `t_vision_*`, `t_alarm_event` | - |
| 용접 현황 | 파트별 센서 값 그래프·표, 기준 이탈, 최근 용접 알람 | 7일 | 10초 | `t_sensor_reading`, `m_recipe_target`, `m_parameter`, `t_alarm_event` | - |
| 비전 검사 현황 | 검사 결과·이미지, 불량 분포, 카메라 상태 | 31일 | 10초 | `t_vision_inspection`, `_detail`, `t_vision_image`, `m_machine` | - |
| Lot 조회 | LOT별 용접·비전 판정, 상세 값 | 31일 | 피드 3초 | `t_lot`, `t_weld_event`, `t_sensor_reading`, `t_vision_*` | - |
| 알람 이력 조회 | 알람 목록·상세·조치 가이드, 확인, 조치 등록 | 31일 | 10초 | `t_alarm_event`, `t_alarm_action` 외 | `t_alarm_event`, `t_alarm_action` |
| 기준정보 관리 | 라인·공정·설비·용접부위·파라미터·레시피 | - | - | `m_*` | `m_*` (ADMIN) |

- Lot, 알람, 비전, 용접 화면에서 **PDF·Excel·CSV**로 내려받을 수 있습니다. PDF·Excel은 10만 행까지, PDF 상세 표는 2,000행까지입니다.
- 화면에 값이 비어 있으면 먼저 **조회 기간**과 **DB에 데이터가 있는지**(18-3)를 확인하세요.
- 계산 방법(합격률, 판정, 알람 상태 등)은 12장에 있습니다.

## 11. 기준정보 관리 (관리자)

1. ADMIN 계정으로 로그인 → 왼쪽 메뉴 **기준정보 관리**
2. 상단 탭 선택: 라인, 공정, 설비, 용접부위, 파라미터, 레시피
3. 새로 만들 때는 입력 후 저장, 고칠 때는 행을 골라 저장
4. 쓰지 않는 항목은 **삭제하지 말고 사용 여부를 `중지`로**

> [!IMPORTANT]
> 기준정보 변경은 **운영 데이터 변경**입니다. 영향 범위와 되돌리기 방법은 14-3을 먼저 확인하세요. 특히 파라미터 코드와 용접부위 순번은 Kepware 기록 값·화면 표시와 직접 연결됩니다(12-5, 13장).

**화면이 없는 기준정보**: 제품(`m_product`), 용접기 상세(`m_weld_machine`), 설비 정격(`m_machine_spec`), 팁 상태(`m_weld_tip_status`)는 DB 담당과 SQL로 등록합니다.
